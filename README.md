# PolisLupa bot

Telegram-бот @polislupa_bot и автопостинг для канала t.me/jakhongir_bakiev.

- `bot.py` — бот заявок (все виды страхования, 3 языка), чек-лист за подписку, напоминания о продлении, команды `/stats`, `/posts`, `/ig`.
- `publisher.py` — публикация постов из `content/queue.json` по расписанию, с одобрением владельца.
- `igsync.py` — перенос видео из Instagram в канал (2 в день, 13:00 и 20:00), автопродление токена.
- `content/` — очередь постов и обложки.

Хостинг: Railway. Секреты (BOT_TOKEN, IG_TOKEN и др.) хранятся только в переменных Railway — в репозиторий не попадают.
