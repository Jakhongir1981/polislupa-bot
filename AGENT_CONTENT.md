# Агент «Аналитик контента» PolisLupa

Запускается по расписанию каждые 8 часов (отдельная сессия Claude). Работает вне контент-плана
вместе с веб-мастером сайта. Задача: найти свежий повод в узбекских источниках и предложить владельцу
(Джахонгиру) публикацию через бота @polislupa_bot. Ничего не публикует сам — только после кнопок владельца.

## Шаг 0. Публикацию статей делать НЕ нужно
Одобренные статьи сайт забирает сам каждые 5 минут (GitHub Actions `proposals.yml` → `GET {BOT}/api/blog/pending`),
а бот после выхода статьи публикует пост в Telegram и карусель в Instagram со ссылкой на неё (воронка).
Ничего не коммить в `polislupa-site` сам. Твоя задача — прислать в `blog_posts` готовый Markdown:
формат — `content/blog/README.md` сайта; uz, ru и en с общим `group`; без `draft`;
`cover: /blog/media/<group>.jpg` (картинку сайт возьмёт из присланной обложки);
кнопка проверки договора — `[Shartnomani tekshirish](/tekshirish/#upload)`.

## Тематическое фото (обязательно для статей)
Добавь в JSON предложения три поля — бот сам найдёт фото на Pixabay и сделает обложку статьи, поста в Telegram
и первый слайд Instagram в фирменной рамке:
- `photo_query` — 2–4 английских слова, что должно быть на фото (например `hospital doctor medicine`,
  `bazaar market stalls`, `car accident road`, `airport travel suitcase`). Без брендов и известных людей.
- `photo_title` — короткий заголовок на узбекском (латиница), до 70 знаков.
- `photo_chip` — рубрика: «Sogʻliq · Здоровье», «Avto · Авто», «Biznes · Бизнес», «Sayohat · Путешествия», «Mulk · Имущество», «Qonun · Закон».

## Шаг 1. Анализ источников
Искать новости и материалы за последние ~24 часа, связанные со страхованием и смежными темами
(ДТП, транспорт, здоровье, имущество, путешествия и визы, бизнес-риски, налоги и законы, банки, погода/ЧС):
kun.uz, gazeta.uz, daryo.uz, spot.uz, uza.uz, podrobno.uz, review.uz, lex.uz (новые законы),
cbu.uz, gov.uz, сайт Агентства по развитию страхового рынка, крупные страховые компании Узбекистана.
Выбрать ОДНУ лучшую тему, полезную обычным людям или бизнесу и не повторяющую последние посты канала
(t.me/s/jakhongir_bakiev) и блога (polislupa.uz/blog/). Все виды страхования, не только авто.
Только проверенные факты со ссылками; цифры и законы — из первоисточника. Не выдумывать.

## Шаг 2. Материалы (фирменный стиль «Самарканд и золото», см. design/)
- **Telegram-пост**: узбекский (латиница), затем `— — —`, русский. HTML (<b>), эмодзи умеренно,
  в конце призыв в бот. До 1000 символов.
- **Обложка** 1080×1080: `design/render.py` (шаблон обложки: theme, icon из lucide, chip, title uz, sub ru).
- **Instagram-карусель** 5–7 слайдов 1080×1350 (`design/render.py`, элементы с полем `body`):
  слайд 1 — цепляющий заголовок, далее по одной мысли, последний — призыв («Batafsil — Telegram-kanalda»).
  Плюс `ig_caption` — подпись (uz, коротко, без HTML).
- **Статья для блога**: uz и ru (по формату сайта), 500–900 слов, практичная, со ссылками на источники.

## Шаг 3. Отправить предложение в бот
`POST {BOT}/api/proposal`, заголовок `X-Key`, JSON:
```
{"id": "2026-11-22-08-tema-slug", "topic": "...", "why": "почему это важно (1–2 предложения)",
 "sources": ["https://..."], "tg_text": "...", "ig_caption": "...",
 "cover": "<base64 PNG>", "slides": ["<base64 PNG>", ...],
 "blog_title": "...", "blog_summary": "...",
 "blog_posts": [{"slug": "...", "lang": "uz", "md": "---\n...frontmatter...\n---\n..."},
                {"slug": "...", "lang": "ru", "md": "..."}]}
```
Ответ `{"ok": true}` — владелец получил предложение с кнопками 📢 Telegram / 📷 Instagram / 📝 Блог / ✅ Везде.

Если ничего стоящего не найдено — не отправлять ничего (лучше пропуск, чем слабый пост).

## Установка инструментов в новой сессии
```
git clone https://github.com/Jakhongir1981/polislupa-bot && cd polislupa-bot/design && npm i
pip install playwright --break-system-packages   # если нет; браузер: /usr/bin/google-chrome
python3 render.py items.json   # → design/out/<id>.png
```
